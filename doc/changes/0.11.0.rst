Surface API
^^^^^^^^^^^

-   This version includes a new "surface" API that allow to represent surface meshes and data.

-   :class:`~surface.PolyMesh` (and :class:`~surface.PolyData`)
    can be used to instantiate mesh (and respectively data) objects with both hemisphere.

-   :class:`~surface.SurfaceImage` are objects that hold meshes and data for both hemispheres.

-   :class:`~surface.SurfaceImage`, :class:`~surface.PolyMesh`, :class:`~surface.PolyData`
    allow you to load and save mesh or data from one hemisphere from or to a Gifti file.
    :class:`~surface.SurfaceImage` can also be instantiated directly with a nifti image and a mesh to project it on.

-   Surface plotting functions have been adapted to work with :class:`~surface.SurfaceImage` object.

-   To facilitate extracting data from those :class:`~surface.SurfaceImage` objects,
    this new release also introduces :class:`~maskers.SurfaceMasker` and :class:`~maskers.SurfaceLabelsMasker`
    as counterparts to the volumetric :class:`~maskers.NiftiMasker` and :class:`~maskers.NiftiLabelsMasker`.

-   Several classes will already accept :class:`~surface.SurfaceImage` and :class:`~maskers.SurfaceMasker` as inputs:
    :class:`~decoding.Decoder`, :class:`~decoding.DecoderRegressor`,
    :class:`~decoding.FREMClassifier`, :class:`~decoding.FREMRegressor`,
    :class:`~glm.first_level.FirstLevelModel`, :class:`~glm.second_level.SecondLevelModel`.
    Moreover :func:`~glm.first_level.first_level_from_bids` will be able to to build :class:`~glm.first_level.FirstLevelModel`
    with the ``fsaverage5`` files generated by fmriprep to directly analysis with surface data.
